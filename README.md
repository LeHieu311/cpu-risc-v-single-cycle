# RISC-V Single Cycle CPU in Verilog

A 32-bit RISC-V Single Cycle CPU implemented in Verilog HDL.

This project is developed for learning RTL Design and Computer Architecture. The CPU supports a subset of the RV32I instruction set and is verified using ModelSim testbenches.

---

## Features

- RV32I Single Cycle Architecture
- 32-bit datapath
- 32 × 32-bit Register File
- Instruction Memory
- Data Memory
- Immediate Generator
- Control Unit
- ALU Control
- ALU
- Program Counter
- Write Back MUX

Supported Instructions

- ADD
- SUB
- AND
- OR
- XOR
- SLT
- ADDI
- LW
- SW
